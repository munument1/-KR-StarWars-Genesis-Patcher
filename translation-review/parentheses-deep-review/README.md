# 전체 설치 파일의 괄호 병기 추가 검색

설치 플러그인 158개의 텍스트 필드 56,056개, Strings 39개의 234,990행, UI/BAT, SST 140개의 활성·비활성 행을 검색했습니다. 후보 숫자는 제거할 문자열 수를 뜻하지 않습니다.

이전 레시피 후보 10곳에 더해 UI 영어 병기 4곳(Depth of Field, VRR, Flip Merge, REPORT)을 확인했습니다. 스페인어 Mi muñequita (내 예쁜 딸에게)는 사용자의 외국어 병기 유지 방침에 따라 context_keep로 분류했습니다. 이전 스페인어 제거 미리보기는 적용하지 않았습니다. source_en이 null인 항목은 영어 대조 자료 없이 현재 표시문을 검수한 기록입니다.

14곳의 정리와 앞서 제거한 비영어 병기 4곳 복구를 [v0.2.3 정식판](../v0.2.3-release/README.md)에 반영했습니다. 요약·기호·식별 코드·기술 이름·말장난은 유지합니다.
