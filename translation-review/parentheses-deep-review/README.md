# 전체 설치 파일의 괄호 병기 추가 검색

이전 번역 레시피 목록에 한정하지 않고, 설치 플러그인 158개의 텍스트 필드 56,056개와 Strings 39개의 234,990행을 직접 읽었습니다. UI/BAT 출력 문자열, HTML 표시 텍스트·이미지 캡션, 비 ASCII 라틴 문자, 다른 괄호 형태도 검색합니다. SST 140개의 활성·비활성 행을 구분해 검색했습니다. 게임·SST 원본은 변경하지 않는 읽기 전용 검사입니다.

이전에 확인한 10곳과 별도로 **새 수정안 5곳**을 찾았습니다.

- UI의 피사계 심도(Depth of Field), 가변 주사율 디스플레이(VRR), 부착 판정(Flip Merge).
- UI의 겹친 따옴표와 괄호로 표시된 신고('REPORT').
- 보충 Free Lanes Strings의 Mi muñequita (내 예쁜 딸에게).

UI 키·줄 순서·줄바꿈을 보존하고, Free Lanes 문자열 ID·나머지 문자열을 보존하는 수정본 2개를 생성·검증했습니다. 영어 대조 자료를 확보하지 않은 현재 표시문 검수이므로 `source_en`은 null입니다. 현재 번역과 수정안 및 정확한 위치를 기록합니다.

원소 기호, 식별 번호, 부품 등급·방향·상태 요약은 유지합니다. DLSS 등의 기술 이름은 `켬 (DLSS)`에서 설정 대상을 지정하므로 번역 중복으로 분류하지 않습니다. 학명과 약어를 만드는 말장난도 일반 영어 중복과 구분합니다. 후보 수는 삭제할 문자열 수를 뜻하지 않습니다.

아직 이 5곳과 앞선 게임 파일 10곳은 배포 EXE에 반영하지 않았습니다. 이미 적용한 SST 239곳은 그대로 유지합니다.
