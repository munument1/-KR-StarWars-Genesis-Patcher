# 바닐라 번역 재사용을 위한 3자 대조

Genesis 8.8.32의 **패치 적용 전 영어 추출본**을 바닐라 영어 및 사용자가 설치해 둔 기존 한국어 Strings와 연결했습니다. 같은 파일명과 StringID를 사용합니다. 설치된 제네시스의 현재 한국어 파일을 영어 원본으로 사용하지 않습니다.

## 결과

개수는 중복 문장을 포함한 **파일별 StringID 위치**입니다. 기존 검수 자료의 고유 문장 수와 직접 비교하면 안 됩니다.

| 구분 | 위치 수 |
|---|---:|
| 전체 대조 | 214,855 |
| 바닐라와 제네시스 영어가 동일 | 177,269 |
| 영어 동일 + 한국어·태그·줄바꿈 검사 통과: 재사용 후보 | 168,750 |
| 제네시스 영어가 변경됨 | 37,496 |
| 제한된 이름 치환 규칙으로 생성한 교체 후보 | 2,825 |
| 이번 추가 번역 원문을 제외한 이름 교체 검수 큐 | 2,821 |
| 대응하는 바닐라 영어 StringID가 없어 보류 | 90 |

**모두 미승인 후보입니다.** 같은 영어여도 기존 한국어의 품질은 별도 검수가 필요합니다. 이름 교체 후 조사는 자동 수정하지 않았으며 `particles_and_context_need_review`로 표시했습니다. 영어가 이름 외에도 바뀌거나, 한국어에 대응 이름이 없거나, 횟수가 다르거나, 태그·줄바꿈이 손상된 경우 후보를 생성하지 않습니다. 부분 치환, 별칭 충돌, 이름과 비슷한 단어의 일부도 보류합니다.

## 자료

- `comparison.jsonl.gz`: 모든 위치의 `vanilla_en` → `vanilla_ko` → `genesis_en` 및 `candidate_ko`. gzip을 풀면 한 줄당 JSON 하나입니다. 바닐라 영어가 없더라도 확보한 한국어 DLC 자료는 유지합니다.
- `term-candidates-0001.json` 등: 이번 추가 번역을 제외한 이름 교체 후보, 250개씩. 검수할 때 세 원문과 교체 내역을 나란히 확인합니다.
- `manifest.json`: 판정별 개수, 파일별 개수, 입력 해시, 실제 사용한 영어 대응 규칙, 예시 및 검수 파일 해시.

예: `UC Prison Shuttle` → `UC 교도소 수송선` → `Imperial Prison Shuttle`이면 `제국 교도소 수송선`을 제안합니다. 문장 전체에서 해당 이름 이외의 영어가 정확하게 일치해야 합니다. `UC`를 일괄적으로 하나의 이름에 대응시키지 않습니다.

이 자료는 Strings 대조만 다룹니다. 플러그인의 인라인 대사까지 재사용을 판정한 결과는 아닙니다. Shattered Space와 추가 콘텐츠의 영어는 `Localization.ba2`뿐 아니라 `Main.ba2`에서도 확보했습니다. 나머지 90개 위치는 영어 참조에 해당 StringID가 없으며, 제네시스의 신규 항목인지 버전 차이인지는 별도 확인해야 합니다. 바닐라 영어와 한국어의 게임 버전이 일치한다는 보장도 없으므로, ID 일치만으로 자동 승인하지 않습니다.

직접 이름을 바꿔도 기존 한국어의 문맥 표현이 그대로 남을 수 있습니다. 예를 들어 `Va'ruun → Sith`를 반영했는데 한국어가 `시스 가문`이 되었다면, 원래의 `가문`을 유지할지 문장별로 검토합니다. 조사·진영 호칭·화자 말투는 기계적 치환만으로 검수 완료 처리하지 않습니다.

게임 파일, 기존 검수 JSON, 배포 설치기에는 적용하지 않았습니다. 생성·검증에 AI 번역 API를 사용하지 않았습니다. 기존 `legacy` 검수 큐와 별도 자료이며, 중복 승인하거나 후보를 바로 설치기에 넣지 않습니다.

## 재현

외부 입력 경로는 로컬에서 지정하며 저장소에는 API 키나 개인 경로를 넣지 않습니다.

```powershell
python scripts/build_three_way_candidates.py --base-data "<Starfield Data>" --audit-dir "<기존 원본 추출 CSV 폴더>" --output-dir "<새 출력 폴더>"
python scripts/test_three_way_candidates.py
python scripts/validate_three_way_candidates.py --review-dir "<출력 폴더>" --base-data "<Starfield Data>" --audit-dir "<원본 추출 CSV 폴더>"
```

기존 출력 폴더가 있으면 생성을 중단합니다. 검수 완료본으로 바뀐 경우 초기 스냅샷 검증 대신 별도 검수 검증 절차가 필요합니다.
