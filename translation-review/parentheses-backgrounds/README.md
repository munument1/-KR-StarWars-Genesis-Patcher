# 괄호 병기와 캐릭터 배경 설명 검수

현재 SST 140개의 유효 행 253,340개, 패처 레시피 248,199개 위치, 보충 DLC Strings 20,135행을 검색했습니다. 원문·번역·수정 위치를 JSON으로 보관합니다.

- 패처에서 영문·한글 중복 병기 216곳을 정리하고, 캐릭터 생성 배경 설명 5곳을 존댓말로 변경합니다. 총 221곳, 플러그인 8개와 Strings 4개입니다.
- 본편 starfield Strings 3종과 Shattered Space dlstrings에서도 병기를 발견했습니다.
- SST 수정본은 234곳입니다. 이 중 2곳은 기존 XP 도움말의 잘못된 HTML 줄바꿈을 원문의 일반 줄바꿈으로 복구합니다.
- `(개조됨)`, `(오픈형)`, 요약·추가 설명, 원소 기호, 시간 기준, 기록 번호와 조작 태그는 보존합니다.
- 약어의 철자로 만드는 말장난, 원문 언어의 발음·어원 설명, 임플란트 등의 실제 식별 코드는 문맥상 유지합니다. 모든 괄호를 문자 규칙만으로 지우지 않습니다.
- 배경 설명 이외의 NPC 대사, 책과 스킬 설명 어투는 변경하지 않습니다.

`recipe-edits.json`은 패처에 반영할 위치, `sst-final-0001.json`은 SST 수정 위치, `candidates.json`은 수정·유지 후보, `character-backgrounds.json`은 직업 배경 설명 대조 기록입니다. `human_reviewed`는 사람의 직접 교열 여부를 표시하며 이번 검수는 Codex 검수입니다.

이전 버전의 입력 25개에 대해 체크섬과 업데이트 결과가 신규 설치 결과와 일치함을 확인했습니다. 실제 게임 플레이 확인은 별도로 필요합니다. xTranslator에서 작업 중인 SST는 닫기 전까지 적용하지 않습니다.
