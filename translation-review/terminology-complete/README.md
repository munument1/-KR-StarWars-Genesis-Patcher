# 전체 용어 검수 완료 자료

SST 140개에서 제외 플래그·빈 값을 제외한 253,340행을 재검색했습니다. 초기 지적 2,988곳과 추가 발견 187곳, 총 3,175곳을 수정 또는 유지로 판정했습니다. 초기 보류 479곳, 그중 API 독립 검사에서 보류되었던 176개 문장 쌍도 최종 판정을 내렸습니다. 최종 자료에는 미결 또는 구조 보류 상태가 없습니다.

| 최종 SST 판정 | 위치 수 |
|---|---:|
| 수정 | 2,976 |
| 문맥상 유지 | 199 |

기존 문장 말투를 유지하며 용어와 조사를 정리했습니다. 원문과 연결이 잘못된 대사, 빠진 문단, 잘못된 Global 변수, 손실된 Alias 태그와 번역된 조작키는 원문에 맞춰 수정했습니다. `Credits`의 돈·자금·사례금, 제국·제국군 및 반란군 약칭, 과학 문장의 비유적 `hyperdrive`는 허용되는 문맥으로 판정합니다. 개발용 식별자와 정상적인 개발자 노트는 유지합니다.

`name-definitions.json`의 40종도 모두 검토했습니다. 표시명 38종에는 프로젝트 표기를 정했고, `You?`의 호칭 차이와 `Horuset I-a`의 표면·궤도 표시는 문맥 변형을 인정합니다. 행성명의 VII/VIII 등은 영어 식별자에 맞춥니다. 프로젝트 표기는 공식 음성·공식 번역 인증을 뜻하지 않습니다.

## 현재 패처 반영

현재 레시피 248,199개 위치(플러그인 37,235개 + Strings 210,964개)를 전부 대조했습니다. v0.2.1에서 추가로 **플러그인 11개·Strings 6개, 1,365곳**을 수정한 v0.2.2 시험판을 만들었습니다. 이 중 **상호작용 `Open` / `ATTX` / `오픈` 18곳을 `열기`로 수정**했습니다. BARC 차량의 `오픈형` 이름은 유지합니다. 본편 Strings의 `Open → 열기`는 이미 올바르게 번역되어 있었습니다.

`applied-patch.json`이 실제 반영 요약입니다. 과거 SST에서 나온 수정 위치 2,976곳이 현재 모드팩에서 모두 사용된다는 뜻은 아닙니다. 현재 레시피의 원문·번역·키를 대조한 수정만 반영했습니다. 원본 SST는 덮어쓰지 않고 최종 수정 자료를 별도 JSON으로 보관합니다.

v0.1.0, v0.2.0, v0.2.1의 수정 대상 17개 파일을 각각 재현한 뒤 업데이트 레시피를 적용하여, 신규 설치 결과와 바이트 단위로 일치하는지 검증했습니다. 실제 게임 폴더에서는 73개 파일 생성·112개 기존 결과 인식이 완료됐습니다. 생성 검증은 게임 파일을 변경하지 않습니다.

이 완료 범위는 **제네시스 용어와 확인된 원문 연결·구조 오류 검수**입니다. 기존 본편 한패의 모든 대사를 문체·오역 관점에서 재번역했다는 뜻은 아닙니다. 기존 한패 자체는 재검수 범위 밖이라는 작업 지침을 유지합니다. 실제 게임 플레이 검증과 잠정 인명의 음성 확인은 별도입니다.

## 자료

- `sst-final-*.json`: 위치별 원문·기존 번역·최종 수정안·유지 이유. 사람이 검수했다는 표시를 하지 않습니다.
- `recipe-edits.json`: 현재 패처의 실제 추가 수정 1,365곳.
- `glossary.json`: 기본 73항목과 추가 확인한 표기 별칭.
- `name-definitions.json`: 표시명 40종의 최종 정책.
- `manifest.json`: 입력 해시, 배치 해시와 전체 검사 수.
- `errors.json`: 최종 구조 오류 0개.
- `update-validation.json`: 버전별 업데이트 출력 일치 결과.

초기 감사와 Gemini 제안은 이전 폴더에 이력으로 유지합니다. 최신 판정은 이 폴더를 사용하세요. API 키·로컬 개인 경로는 포함하지 않습니다.

재현: `scripts/complete_terminology_review.py --repo <저장소> --sst-csv <검증된 원본 CSV> --output-dir <별도 새 폴더>`. API 호출 없이 원문별 문맥 결정과 확정 표기 규칙을 적용합니다.
