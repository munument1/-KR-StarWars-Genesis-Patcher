# 통일 용어집과 ESM/SST 용어 재검수

## 기준 및 범위

- 사람용 기준: [`../GLOSSARY.md`](../GLOSSARY.md), 73항목.
- 프로그램·번역 AI용 기준: `glossary.json`. 영어 별칭, 표준 한국어, 기존 혼용 표기, 잠정 상태, 문맥 제한, SST 발견 근거를 포함합니다.
- 원본 SST 140개, 288,054행의 스냅샷을 실제 SST와 전부 대조해 일치하는 것을 확인했습니다. 파일별 해시·마스터 목록은 `source-verification.json`에 있습니다.
- 제외 플래그 및 빈 값 34,714행을 빼고 253,340행을 검색했습니다. 같은 문장은 SST와 적용 위치가 다르면 별도 위치입니다.
- 현재 패처가 사용하는 ESM/ESP 플러그인 140개의 37,235개 번역 위치도 별도로 검사했습니다. 자기 SST가 없는 플러그인도 실제 적용 레시피를 검사합니다.
- 본편 기존 한패의 전체 문체·오역 교열은 범위 밖입니다. 제네시스 용어의 표기·진영명·장소명 통일을 검사합니다.

## 현재 플러그인 결과

용어 지적 위치 987개를 기준으로 분류했습니다.

| 판정 | 위치 수 |
|---|---:|
| 표기·조사 보정 규칙으로 수정안 검증 | 974 |
| 원문과 문맥을 읽고 수정안 검증 | 8 |
| 잠정 인명 표기로 통일한 수정안 | 1 |
| 약칭·의역이 문맥상 타당해 기존 표현 유지 | 4 |

**수정안 983개를 v0.2.1 시험판의 ESM/ESP 55개에 반영했습니다.** 적용 보고서는 `applied-patch.json`, 생성·업데이트 검증 설명은 [`../../docs/terminology-patch.md`](../../docs/terminology-patch.md)에 있습니다. 이 폴더의 원래 감사 자료와 입력 해시는 반영 전 스냅샷을 유지합니다. Janese는 제니스라는 프로젝트 잠정 표기를 유지하고 게임 음성 확인이 남았음을 표시했습니다. `human_reviewed: false`는 사람이 검수했다는 표시를 하지 않는다는 뜻입니다. 문맥 검토에는 `review_method: codex_context_review`를 기록합니다.

예: 블래스터→블라스터, 라이트세이버/광검→광선검, 반란 연합→반란군 연합, 그림자 집단→섀도우 콜렉티브. 표기에 붙은 조사도 받침에 맞추며, 게임 태그·조작 토큰·자리표시자·줄바꿈은 보존합니다.

## 과거 SST 자료

과거 SST에서 찾은 지적 위치는 2,988개입니다. 2,498개는 규칙으로, 5개는 문맥 검토로, 1개는 잠정 인명 표기로 수정안을 만들었습니다. 5개는 기존 표현을 유지합니다. **초기 감사의 문맥 확인 463개, 일부 용어만 해결한 13개, 구조 보류 3개는 [`../terminology-followup/README.md`](../terminology-followup/README.md)에서 추가 검수했습니다.** 이는 현재 패처에 전부 적용되어 있는 항목 수가 아닙니다. 현재 적용 자료의 검수 결과를 우선하고, 과거 SST에 승인되지 않은 문구를 자동 적용하지 않습니다.

`unresolved-names.json`의 40종은 용어집 밖에서 번역이 갈리는 이름·장소 후보입니다. 일반 표현 `You?`, 약칭, 표면/궤도 구분, 바닐라 표현도 섞여 있으므로 다수 표기를 자동으로 정답으로 채택하지 않습니다. 로마 숫자가 다른 행성명은 이름 표기 통일과 별도로 확인해야 합니다.

## 파일 및 재현

- `plugin/plugin-0001.json` 등: 현재 ESM별 수정안과 원문·FormID·필드·인덱스.
- `sst/sst-0001.json` 등: 원본 SST별 지적 사항과 수정안·보류 사유.
- `manifest.json`: 검사 개수·판정 개수·입력 및 출력 해시.
- `glossary.json`의 `observed_exact_translations`: 출처를 가진 표기 후보입니다. `approved_alias: false`인 값은 사용 빈도만으로 승인하지 않습니다.

```powershell
python scripts/audit_sst_terminology.py --audit-dir "<원본 CSV 폴더>" --output-dir "<새 출력 폴더>" --source-verification "<SST 스냅샷 검증 JSON>"
python scripts/test_sst_terminology.py
python scripts/validate_sst_terminology.py --review-dir "<출력 폴더>"
```

출력 폴더가 이미 있으면 중단합니다. 게임·원본 SST·배포 설치기에는 쓰지 않으며 AI API를 호출하지 않습니다. 용어집 밖의 모든 고유명 및 모든 대사 품질까지 검수가 끝났다는 뜻은 아닙니다.
