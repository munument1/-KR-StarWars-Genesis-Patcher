# 괄호 병기 추가 검색

v0.2.3의 216곳은 전체 괄호 수가 아니라, 해당 버전에서 정리한 번역 위치 수입니다. 미리 정한 영문 목록과 한글 바로 뒤의 괄호 조건 때문에 숫자로 끝나는 이름과 일부 약어를 놓쳤습니다.

범위를 넓혀 현행 패처에서 1,181개 괄호 후보를 검색했습니다. 조작키, 원소 기호, 부품 등급, 방향·상태 요약도 포함되므로 전부 삭제 대상으로 볼 수는 없습니다. 추가로 확인한 중복은 `recipe-edits.json`에 기록합니다. 밴도-3의 숫자 접미사와 BARC·CIS·EARS·EM 병기를 정리합니다. 가축의 크기를 뜻하는 stock을 주식으로 잘못 번역한 항목도 가축으로 수정합니다.

이번 기록은 후속 수정안이며 아직 게임 파일·배포 EXE에는 반영하지 않았습니다. v0.2.3은 변경하지 않았습니다.

사용자가 예로 든 exertion(노력) 2곳과 제네시스 시작 안내의 저장(SAVE)은 현행 설치 게임 파일에서 번역만 남아 있음을 레코드 단위로 확인했습니다. SST 원본은 xTranslator 작업 중이라 이전 단계의 234곳도 미적용 상태입니다. SST 화면과 적용된 게임 파일은 현재 다를 수 있습니다.

## 2026-10-08 SST 원본 적용 완료

사용자가 xTranslator를 종료한 뒤 SST 8개, 번역 239곳을 원본 백업 후 반영했습니다. 앞서 준비한 234곳과 후속 검색에서 대응한 SST 위치를 합쳤으며, 중복 위치는 한 번만 수정했습니다. 별도 파서로 SST 140개·288,054행을 읽어 대상 이외 번역, 원문·플래그·ID·레코드 해시 보존을 검증했습니다. 수동 작업과 충돌한 항목은 없습니다. `sst-applied-items.json`은 실제 반영 항목이고 `sst-application.json`은 검증 결과입니다.

위의 SST 미적용 안내는 적용 전 상태의 기록입니다. 후속 게임 파일 10곳과 배포 EXE는 이번 SST 적용으로 바뀌지 않았습니다.


v0.2.3 정식판에서 레시피 추가 10곳과 UI 추가 4곳을 반영했습니다. 영어 외 언어 병기 4곳은 복구했습니다. [최종 적용·검증 기록](../v0.2.3-release/README.md)을 확인하세요.
