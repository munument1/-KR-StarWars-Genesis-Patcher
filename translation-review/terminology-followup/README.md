# 과거 SST 용어 추가 검수

**이 폴더는 중간 검사 이력입니다. 보류 176개 문장 쌍을 포함한 최종 검수는 [`../terminology-complete/README.md`](../terminology-complete/README.md)에서 완료했습니다. 아래 수치는 당시 결과를 보존합니다.**

초기 용어 감사에서 보류된 479개 위치를 다시 검토했습니다. 현재 패처의 확정 수정 983곳과 별개인 과거 SST 자료입니다. 원본 SST와 게임 파일은 수정하지 않습니다.

## 규칙 및 문맥 필터

`manifest.json`, `recheck-*.json`은 AI 호출 전 결과입니다.

| 분류 | 위치 수 |
|---|---:|
| 규칙으로 수정안 검증 | 61 |
| 일부 용어만 수정 | 9 |
| 문맥상 기존 번역 유지 | 97 |
| 개발용 식별자 유지 | 13 |
| 문맥 확인 필요 | 296 |
| 구조 보류 | 3 |

`glossary-extensions.json`에는 추가로 확인한 기존 표기 별칭이 있습니다. `Credits`의 돈·보상, 제국군 등의 자연스러운 약칭은 문맥 필터로 보존했습니다. 기본 한패의 일반적인 문체·표현은 재번역하지 않습니다.

## Gemini 검수와 독립 검사

남은 문장을 중복 제거하여 293개 문장 쌍, 308개 위치를 Gemini 3.5 Flash-Lite로 검수했습니다. `ai-manifest.json`, `ai-review-*.json`에 원문, 기존 번역, 제안, 모델 설명과 독립 검사 결과를 기록합니다. API 키와 개인 경로는 포함하지 않습니다.

| 독립 검사 결과 | 문장 쌍 수 |
|---|---:|
| 용어 수정 제안의 구조·범위 검사 통과 | 99 |
| 기존 번역 유지 | 9 |
| 개발용 식별자 유지 | 9 |
| 용어 외 문구 변경 또는 미등록 표기로 범위 보류 | 122 |
| 표준 용어 누락·혼용으로 보류 | 48 |
| 태그·줄바꿈·조작 토큰 불일치로 보류 | 6 |

모델의 “유지” 판정을 그대로 승인하지 않고 용어집과 다시 대조했습니다. 게임 태그 내부에만 등장하는 이름은 일반 대사 용어로 취급하지 않습니다. `scope_hold`는 실제 재작성 외에도 검증되지 않은 별칭을 포함하므로 모두 잘못된 번역이라는 뜻은 아닙니다.

**99개 제안은 자동 검사 통과 자료이며 최종 승인·게임 반영 자료가 아닙니다.** 보류 176개는 문맥 또는 구조 확인이 필요합니다. AI 결과 전체는 원본 SST와 설치기에 자동 적용하지 않습니다. 사람이 검수했다고 표시하지 않습니다.

고유명 후보 40종은 [`../terminology/unresolved-names.json`](../terminology/unresolved-names.json)에 남아 있습니다. 바닐라 표현의 혼용, `You?` 같은 문맥 의존 표현과 표면·궤도 이름을 하나의 용어로 강제 합치지 않습니다. 행성명 로마 숫자 차이는 원문 식별자 확인이 필요합니다.

재현 스크립트: `scripts/recheck_remaining_sst.py`, `scripts/export_terminology_ai_review.py`. 첫 스크립트는 규칙 검사만 수행하고 API를 호출하지 않습니다. 두 번째는 이미 확보한 API 결과를 검사·정리하며 키를 읽거나 API를 호출하지 않습니다.
