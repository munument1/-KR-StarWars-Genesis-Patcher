# v0.2.3 정식판 추가 반영

앞선 시험판 이후 영어 병기 14곳(레시피 10, UI 4)을 정리하고 영어 외 언어 병기 4곳을 복구했습니다. 스페인어 Mi muñequita 병기는 유지합니다. 캐릭터 생성 배경의 존댓말 수정은 앞선 시험판에서 반영된 내용을 유지합니다.

recipe-edits.json에는 텍스트 레시피 수정 14곳(신규 정리 10, 외국어 복구 4)을 기록했습니다. UI의 4곳은 ../parentheses-deep-review/items.json에 있으며 스페인어 후보는 context_keep로 분류했습니다. validation.json에서 설치·갱신 검증 및 적용 결과를 확인할 수 있습니다. sst-edits.json은 기존 SST에 반영된 외국어 병기 4곳의 복구 기록이며, 원문·플래그·레코드 메타데이터는 보존했습니다.

영어 중복 병기만 정리하며 비영어 원문 병기, 요약과 추가 설명, 식별 코드 및 말장난은 유지합니다. source_en이 null인 UI 항목은 현재 표시문을 검수한 자료입니다.
