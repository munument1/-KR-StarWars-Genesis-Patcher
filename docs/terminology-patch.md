# v0.2.1 용어 통일 시험판

통일 용어집 73항목을 기준으로 현재 플러그인 번역을 검사해 확정한 **983개 위치를 ESM/ESP 55개에 반영**했습니다. 블래스터→블라스터, 라이트세이버/광검→광선검, 반란 연합→반란군 연합 등 이름과 붙은 조사를 보정합니다. 문맥상 타당한 약칭·의역 4곳은 유지합니다.

9곳은 개별 문맥을 확인한 수정이며, 그중 Janese는 제니스라는 프로젝트 잠정 표기로 통일했습니다. 음성 확인이 끝난 공식 표기라는 뜻은 아닙니다.

v0.2.0의 기존 한패 활용, 이번 추가 번역, 한글 폰트·HUD·BAT·보충 DLC Strings는 유지합니다. 기존 본편 한패의 문체와 번역 품질을 일괄 교열하지 않습니다. 원본 SST의 미확정 AI 수정안을 패처에 자동으로 넣지 않습니다.

원본으로 새로 만든 결과와 이전 패치에서 업데이트한 결과가 수정한 플러그인 55개 모두 바이트 단위로 일치했습니다. 실제 게임 폴더를 대상으로 생성 단계에서 플러그인 55개와 이전 Strings 변경 13개를 함께 검증했습니다. 검사 과정에서 게임 파일은 변경하지 않았습니다.

현재 설치 상태가 지원하는 원본 또는 이전 패치의 정확한 해시와 일치할 때만 업데이트합니다. 사용자 수정 파일은 덮어쓰지 않으며 기존 백업·복원 기능을 사용합니다. 실제 게임 플레이 검증은 남아 있습니다.

반영 요약은 [`translation-review/terminology/applied-patch.json`](../translation-review/terminology/applied-patch.json), 과거 SST의 추가 검수는 [`translation-review/terminology-followup`](../translation-review/terminology-followup/)에 보관합니다.
