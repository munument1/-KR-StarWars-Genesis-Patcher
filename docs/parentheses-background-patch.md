# v0.2.3 정식판 — 괄호 병기·캐릭터 배경 설명 정리

Genesis 8.8.32용 한국어 패처입니다. v0.2.3 시험판을 정식판으로 갱신했습니다.

- v0.2.2 대비 영어·한글 중복 병기 226곳을 정리하고 캐릭터 생성 배경(직업) 설명 5곳을 존댓말로 맞췄습니다.
- 앞선 v0.2.3 시험판에서 추가로 찾은 영어 병기 14곳을 정리했습니다. UI 설정 설명, 신고 버튼 안내 및 플러그인·본편 Strings에 반영했습니다. 가축을 주식으로 옮긴 문구도 바로잡았습니다.
- 영어 외 언어의 원문 병기는 유지합니다. 앞서 제거한 hermanita, vod, Veshh ka'nik, Shak'kra ven dross 병기 4곳을 복구했습니다. Mi muñequita (내 예쁜 딸에게)도 유지합니다.
- 요약·추가 설명, 원소 기호, 식별 코드, 조작 태그와 말장난에 필요한 원문은 유지합니다.
- 기존 용어 통일, 오픈 → 열기 수정, 한글 메뉴, Pretendard 폰트, 원형 HUD 행성 이름 간격 보정, 보충 DLC Strings 및 한국어 BAT 안내를 포함합니다.

`GenesisKRPatcher-v0.2.3.zip`을 풀고 게임을 완전히 종료한 뒤 EXE를 실행하세요. mods·profiles·ModOrganizer.ini가 있는 Genesis Game 폴더를 선택하고 **검사하고 패치 생성 → 백업 후 적용**까지 진행합니다. 이전 v0.2.3 시험판을 포함한 기존 적용자도 같은 절차로 갱신할 수 있습니다. 게임 언어는 English로 유지합니다. 적용 전 파일을 백업하며 Steam 본편 Data는 수정하지 않습니다.

변경 대상 텍스트의 이전 입력 13개에서 갱신 결과가 신규 설치 결과와 같은지 확인했습니다. 알려진 이전 UI 파일만 갱신하며 임의 수정된 파일은 거부합니다. 단위 검증 21개, EXE 내장 데이터 185개 작업 및 생성 파일을 확인했습니다. 메뉴·폰트·HUD는 앞서 실제 게임에서 확인했습니다. 전체 퀘스트와 대사의 실제 플레이 검증 및 기존 번역 전체의 사람 교열은 완료되지 않았습니다.
