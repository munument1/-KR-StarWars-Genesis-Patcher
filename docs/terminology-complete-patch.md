# v0.2.2 전체 용어 검수·상호작용 수정 시험판

전체 SST의 유효 행 253,340개를 재검색하고, 초기 보류를 포함한 지적 3,175곳의 용어 판정을 완료했습니다. 현재 패처 레시피 전부를 대조하여 v0.2.1에 더해 **1,365곳을 플러그인 11개와 Strings 6개에 반영**합니다.

상호작용이 `오픈`으로 나오던 원인은 모드 ESM의 `ATTX` 필드였습니다. 원문이 정확히 `Open`인 해당 필드 18곳을 **열기**로 통일했습니다. 본편 Strings의 기존 열기 번역과 차량의 오픈형 이름은 유지합니다.

혼용 이름·조사뿐 아니라 원문과 다른 대사가 붙은 사례, 조작키·태그·문단 손상도 수정했습니다. 문맥상 타당한 약칭과 돈·보상 등의 의역은 유지합니다. 본편 기존 한패의 모든 대사 문체·오역을 다시 교열한 것은 아닙니다.

v0.1.0·v0.2.0·v0.2.1에서 업데이트한 결과는 각각 신규 설치와 일치합니다. EXE의 내장 데이터와 게임 폴더 대상 생성 결과도 검증합니다. 한글 폰트·HUD·BAT·보충 DLC Strings를 포함합니다. 게임 파일은 검증 중 덮어쓰지 않았으며, 실제 게임 플레이 확인은 남아 있습니다.

1. 게임을 완전히 종료합니다.
2. `GenesisKRPatcher.exe`에서 mods·profiles·ModOrganizer.ini가 있는 Game 폴더를 선택합니다.
3. 검사 및 패치 생성 후 **백업 후 적용**을 실행합니다.
4. MO2의 Star Wars Genesis Compiler 프로필에서 SFSE로 실행합니다.
