# 기존 한패 활용 및 제네시스 용어 보정 시험판

v0.2.0 소스 및 시험판에서 적용합니다. 공개 v0.1.0 릴리즈 파일은 그대로입니다.

바닐라 영어·사용자의 기존 한국어 Strings·제네시스의 패치 전 영어를 같은 파일명과 StringID로 연결합니다. 영어가 동일하면 기존 한패를 그대로 사용하고, 영어의 변경이 아래 이름 교체로만 구성되면 해당 한국어 이름과 붙은 조사만 보정합니다. **기존 한패 자체의 문체·오역 교열은 이번 작업 범위에 포함하지 않습니다.**

## 결과

- 이번 추가 번역 원문 11,108개 적용 위치는 유지합니다.
- 기존 한패 활용 대상 167,946개 위치, 이름 보정 대상 2,821개 위치를 선택했습니다.
- 현재 패치와 실제로 달라지는 위치는 기존 한패 활용 7,738개, 이름 보정 2,423개입니다. 이미 같은 번역인 항목은 결과가 달라지지 않습니다.
- 본편 및 DLC의 13개 Strings 파일을 갱신합니다. 플러그인 번역·폰트·HUD·BAT·보충 DLC Strings는 기존 패키지 자료를 유지합니다.
- 영어 문장 내용이 다르거나 이름의 개수가 맞지 않는 항목은 기존 패치의 번역을 유지합니다.
- AI API 호출은 없습니다.

## 제한된 용어 대응표

문장 전체에서 다른 영어가 정확하게 같을 때만 아래 대응을 인정합니다. 영어가 바뀌지 않았으면 바닐라 이름을 스타워즈 이름으로 일괄 치환하지 않습니다.

| 바닐라 영어 | 제네시스 영어 | 한국어 |
|---|---|---|
| Neon | Nar Shaddaa | 나르 샤다 |
| New Atlantis | Coruscant | 코러산트 |
| UC | Empire / Imperial | 제국 |
| United Colonies | Galactic Empire | 은하 제국 |
| United Colonies | Empire | 제국 |
| Aurora | Spice | 스파이스 |
| Vasco | ND-5 | ND-5 |
| Mars | Geonosis | 지오노시스 |
| House Va'ruun / Va'ruun | Sith | 시스 |
| Ecliptic | Trandoshan / Trandoshans | 트랜도샨 |

`은/는`, `이/가`, `을/를`, `과/와`, `으로/로`는 바뀐 이름의 받침에 맞춥니다. `으로/로`는 ㄹ 받침 예외를 반영하고, `ND-5`는 ‘엔디 파이브’의 끝소리를 사용합니다. 조사가 단어의 일부인 경우 치환하지 않습니다. 바룬을 시스로 바꿀 때 기존 번역의 `바룬 가문`도 이름 단위로 처리합니다.

게임 태그·조작 토큰·자리표시자·줄바꿈이 맞지 않으면 새 번역을 넣지 않습니다. 부분적으로만 바뀐 동일 이름, 상충하는 별칭, 태그 안의 이름도 보류합니다.

## 설치 및 검증

시험판은 원본 제네시스와 공개 v0.1.0이 적용된 파일을 지원합니다. 이전 패치의 **정확한 파일 해시**와 일치할 때만 갱신하며 사용자 수정 파일을 덮어쓰지 않습니다. 기존 백업·복원 방식을 사용합니다.

원본으로 생성한 결과와 기존 패치에서 갱신한 결과가 13개 파일 모두 바이트 단위로 일치하는 것을 확인했습니다. 실제 게임 폴더를 대상으로 생성 단계도 검증했으며 게임 파일에는 아직 적용하지 않았습니다. 변경된 대사의 실제 플레이 검증은 남아 있습니다.

결과 요약과 이름 교체 내역은 [`translation-review/donor-reuse`](../translation-review/donor-reuse/)에 보관합니다. `human_reviewed: false`는 문장별 사람 교열을 완료했다는 뜻이 아니라, 영어 동일성·용어 대응·구조 검사로 반영했다는 표시입니다.
